# 💈 Barbershop - Plataforma de Barbería

![Estado del Proyecto](https://img.shields.io/badge/Estado-En%20Desarrollo-green)
![Licencia](https://img.shields.io/badge/Licencia-MIT-blue)

**Barbershop** es una aplicación web moderna diseñada para digitalizar y optimizar la gestión de servicios en una barbería. Permite a los usuarios conocer los servicios, horarios y realizar reservaciones de manera sencilla.

---

## 🚀 Características

- **Landing Page Atractiva:** Presentación de la barbería con un diseño moderno y responsive.
- **Gestión de Servicios:** Catálogo detallado de cortes y tratamientos disponibles.
- **Sistema de Reservas:** (Si aplica) Formulario para agendar citas de manera eficiente.
- **Sección de Contacto:** Integración con redes sociales y ubicación del local.
